Entry for the make.fun bounty "The Internet in One Word": describe the whole
internet in a single word. The program writes that word — and nothing else —
to `/output/entry.txt`.

**The word: `doomscrolling`**

The endless scroll through bad news that defines the modern internet: funny
by itself, true of the whole thing, and not the first obvious word anyone
reaches for. It makes a reader laugh, and then nod.

Run with `node main.ts` (Node 22+). Set `MAKEFUN_OUTPUT_DIR` to write
elsewhere (default `/output`).
